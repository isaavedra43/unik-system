# UI Quality Rubric — UNIK

Cada UI nueva se autoevalúa 0–10:

| Criterio            | Peso |
| ------------------- | ---- |
| Visual hierarchy    | 1x   |
| Consistency         | 1.5x |
| Spacing             | 1x   |
| Typography          | 1x   |
| Responsiveness      | 1.5x |
| Accessibility       | 1.5x |
| Information density | 1x   |
| Interaction states  | 1x   |
| Motion              | 0.5x |
| Performance         | 1x   |

## Mínimo aceptable

- Promedio ≥ 8.5
- Ninguna categoría < 7

Si no cumple, la tarea visual NO está terminada.

## Checklist rápida

- [ ] Sin hardcoded colors.
- [ ] Sin componentes duplicados.
- [ ] Responsive en 1366, 1024, 768, 390.
- [ ] Estados loading/empty/error.
- [ ] Labels asociados a inputs.
- [ ] Focus visible.
- [ ] Botones con estados.
- [ ] No overflow horizontal.
- [ ] Design tokens usados.
- [ ] Build, lint y typecheck pasan.
